# Slimes Base

Nombre del juego: Slimes Base

## Descripción

Slimes Base es un juego 2D de supervivencia, crianza y automatización inspirado en Slime Rancher, pero en vista lateral 2D. El jugador explora biomas, captura slimes, los alimenta, los hace evolucionar y construye una colonia autosustentable.

## Biomas principales

- Naturaleza
- Fuego / Volcán
- Hongos
- Hielo

## Personajes

- Explorador: cava, explora y captura slimes.
- Criador / Ingeniero: alimenta slimes, construye y maneja la base.

## Objetivo

Crear una colonia viva y autosustentable de slimes.
