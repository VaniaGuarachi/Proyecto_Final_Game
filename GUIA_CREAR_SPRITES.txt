¿QUÉ SON LOS SPRITES?
═════════════════════

Los sprites son imágenes 2D que usas en tu juego.
Para la tienda necesitas 4 imágenes (una por cada slime).

TAMAÑO RECOMENDADO
═══════════════════

Cada sprite debe medir:
  • Ancho: 200 píxeles
  • Alto: 200 píxeles
  • Formato: PNG (para que tengan transparencia)

═════════════════════════════════════════════

Puedes usar:
  • ChatGPT con DALL-E
  • Midjourney
  • Stable Diffusion
  • Leonardo.ai

200x200 pixels. PNG format."

OPCIÓN 2: CREAR LAS IMÁGENES TÚ MISMO
═════════════════════════════════════

HERRAMIENTA 1: ASEPRITE (La mejor, pero de pago)
────────────────────────────────────────────────
1. Descarga Aseprite: https://www.aseprite.org/
2. Crea un proyecto 200x200
3. Dibuja tu slime
4. Export como PNG

HERRAMIENTA 2: PIXILART (Gratis, online)
──────────────────────────────────────────
1. Ve a: https://www.pixilart.com/
2. Click "Create"
3. Tamaño: 200x200
4. Dibuja tu slime
5. Download como PNG

HERRAMIENTA 3: GIMP (Gratis, poderoso)
────────────────────────────────────────
1. Descarga: https://www.gimp.org/
2. File → New → 200x200
3. Dibuja tu slime
4. Export as PNG

HERRAMIENTA 4: KRITA (Gratis, muy bueno)
──────────────────────────────────────────
1. Descarga: https://krita.org/
2. File → New → 200x200
3. Dibuja tu slime
4. Export as PNG

CÓMO DIBUJAR UN SLIME SIMPLE (Tutorial rápido)
═════════════════════════════════════════════

SLIME ROSA:
───────────

Paso 1: Forma básica
  Dibuja un círculo rosado (como una pelota)
  
Paso 2: Movimiento
  Haz que parezca que está saltando (debajo más ancho que arriba)
  
Paso 3: Ojos
  Dibuja dos puntos negros grandes
  
Paso 4: Brillo
  Agrega un pequeño triángulo blanco en la esquina (efecto de brillo)

Paso 5: Bordes
  Agrega una línea oscura alrededor (contorno)

RESULTADO:
  Una forma de gota rosa con ojos grandes y una sonrisa

SLIME PLANTA:
─────────────

Lo mismo que el slime rosa, pero:
  • Color: Verde
  • Agrega hojas pequeñas en la parte superior
  • Dibuja flores pequeñas (opcional)

SLIME FUEGO:
────────────

Lo mismo que el slime rosa, pero:
  • Color: Naranja/Rojo
  • En lugar de ser liso, tiene forma de llamas
  • Agrega líneas amarillas dentro (efecto fuego)
  • Los bordes pueden ser más dentados

SLIME TOXICO:
──────────────

Lo mismo que el slime rosa, pero:
  • Color: Morado oscuro o verde oscuro
  • Agrega pequeños círculos verdes alrededor (burbujas de veneno)
  • Puede tener una expresión más seria/maligna
  • Agrega detalles de "ácido" alrededor

PASOS FINALES: CÓMO IMPORTAR LOS SPRITES A UNITY
═════════════════════════════════════════════════

1. Guarda tus 4 imágenes PNG como:
   • SlimeRosa.png
   • SlimePlanta.png
   • SlimeFuego.png
   • SlimeToxico.png

2. En tu carpeta del proyecto, ve a: Assets → Sprites

3. Copia y pega las 4 imágenes aquí
   (O arrastra y suelta desde tu carpeta de descargas)

4. En Unity, verás que aparecen en la carpeta Sprites

5. Selecciona CADA imagen y en el Inspector:
   • Texture Type: Sprite (2D and UI)
   • Sprite Mode: Single
   • Click "Apply"

6. ¡Listo! Ya puedes usarlas en la tienda

CONSEJOS PARA QUE LOS SPRITES SE VEAN BIEN
═════════════════════════════════════════════

✓ Usa colores VIVOS (rosa, verde, naranja, morado)
✓ Dibuja OJOS grandes y expresivos
✓ Haz los slimes REDONDOS y suaves
✓ Agrega un CONTORNO (línea oscura alrededor)
✓ Usa SOMBRAS para dar profundidad
✓ Agrega BRILLOS (puntos blancos)
✓ Crea un patrón único para cada slime
