FLUJO DE DATOS: PASO A PASO
═════════════════════════════

Momento 1: JUGADOR ENTRA A LA TIENDA
────────────────────────────────────

Personaje
   ↓ (entra en collider)
ShopTrigger.OnTriggerEnter2D()
   ├─ Verifica si es el jugador
   ├─ playerInShopZone = true
   └─ Mensaje: "¡Entraste a la tienda!"

Momento 2: JUGADOR PRESIONA "T"
───────────────────────────────

Teclado: T presionado
   ↓ (cada frame)
ShopTrigger.Update()
   ├─ Verifica: playerInShopZone == true?
   ├─ Verifica: Input.GetKeyDown(T)?
   └─ Si ambas son true → OpenShop()

Momento 3: ABRE LA TIENDA
─────────────────────────

ShopUI.OpenShop()
   ├─ shopPanel.SetActive(true) ← Muestra el panel
   ├─ GameManager.PauseGame() ← Pausa el juego
   ├─ UpdateCrystalsDisplay() ← Muestra cristales
   └─ CreateSlimeButtons() ← Crea botones

CreateSlimeButtons()
   ├─ Obtiene datos de SlimeShopData
   ├─ Para cada slime:
   │  ├─ Crea un botón
   │  ├─ Asigna imagen
   │  ├─ Asigna nombre
   │  └─ Asigna listener
   └─ Selecciona el primer slime

Resultado: ✓ Tienda abierta, puedes ver los 4 slimes

Momento 4: JUGADOR HACE CLICK EN UN SLIME
──────────────────────────────────────────

Button → OnSlimeButtonClicked(index)
   ├─ Obtiene datos del slime
   ├─ Muestra imagen
   ├─ Muestra nombre
   ├─ Muestra precio
   ├─ Muestra descripción
   ├─ Cambia color del botón (seleccionado)
   └─ Actualiza estado del botón COMPRAR

Resultado: ✓ Ves la información del slime

Momento 5: JUGADOR HACE CLICK EN "COMPRAR"
──────────────────────────────────────────

Button → OnBuyButtonClicked()
   ├─ Obtiene el slime seleccionado
   ├─ Llama a SlimeShopData.BuySlime(index)
   │
   └─ SlimeShopData.BuySlime()
       ├─ Verifica: ¿Tengo dinero?
       │  └─ Llama a CanBuySlime()
       │
       ├─ Si tengo dinero:
       │  ├─ Llama a ResourceManager.SpendResource("Cristales", precio)
       │  ├─ Cristales bajan
       │  ├─ Retorna true
       │  └─ ShopUI recibe true
       │
       └─ Si NO tengo dinero:
           ├─ Retorna false
           └─ ShopUI recibe false

ShopUI.OnBuyButtonClicked()
   ├─ Si compra fue exitosa:
   │  ├─ Debug.Log("¡Compraste X!")
   │  └─ Actualiza pantalla
   │
   └─ UpdateCrystalsDisplay()
       ├─ Obtiene cristales actuales
       ├─ Actualiza el texto
       └─ Actualiza botón COMPRAR (habilitado/deshabilitado)

Resultado: ✓ Compra realizada, cristales cobrados

Momento 6: JUGADOR PRESIONA "CERRAR"
─────────────────────────────────────

Button → OnCloseButtonClicked()
   ├─ Llama a CloseShop()
   │
   └─ ShopUI.CloseShop()
       ├─ shopPanel.SetActive(false) ← Oculta el panel
       ├─ GameManager.ResumeGame() ← Reanuda el juego
       └─ ¡Tienda cerrada!

Resultado: ✓ Tienda cerrada, vuelves al juego

TIMELINE: SECUENCIA DE EVENTOS
════════════════════════════════

1. Inicio del juego
   └─ GameManager, ResourceManager, ShopManager se crean

2. Jugador entra a zona de tienda
   └─ ShopTrigger detecta entrada

3. Jugador presiona "T"
   └─ ShopUI.OpenShop() se ejecuta
   └─ Tienda se muestra

4. Tienda está abierta
   ├─ Jugador ve los 4 slimes
   ├─ Puede hacer click para ver detalles
   └─ Puede hacer click en "Comprar"

5. Jugador compra un slime
   ├─ SlimeShopData.BuySlime() se ejecuta
   ├─ Cristales se restan
   └─ Pantalla se actualiza

6. Jugador presiona "Cerrar"
   └─ ShopUI.CloseShop() se ejecuta
   └─ Tienda se oculta
   └─ Juego continúa
