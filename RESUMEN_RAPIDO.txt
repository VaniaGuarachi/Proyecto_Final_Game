═════════════════════════════════════════════════════════════════════════════

TAREAS QUE DEBES HACER EN UNITY:
═════════════════════════════════

TAREA 1: En MainScene, crea la zona de tienda (5 min)
┌─────────────────────────────────────────────────────┐
│ 1. Create Empty → Renombra: "ShopArea"              │
│ 2. Add Component → BoxCollider2D                    │
│ 3. Marca "Is Trigger" ✓                             │
│ 4. Add Component → ShopTrigger                      │
│ 5. Ajusta el collider al tamaño de tu tienda        │
└─────────────────────────────────────────────────────┘

TAREA 2: Copia el Canvas de Tienda.unity a MainScene (2 min)
┌─────────────────────────────────────────────────────┐
│ 1. Abre Tienda.unity                                │
│ 2. Selecciona ShopCanvas                            │
│ 3. Ctrl+C (copiar)                                  │
│ 4. Abre MainScene                                   │
│ 5. Ctrl+V (pegar)                                   │
│ 6. En ShopArea/ShopTrigger → Asigna el ShopUI       │
└─────────────────────────────────────────────────────┘

TAREA 3: Configura los datos de los slimes (3 min)
┌─────────────────────────────────────────────────────┐
│ 1. En Tienda.unity (o MainScene):                   │
│ 2. Create Empty → Renombra: "ShopManager"           │
│ 3. Add Component → SlimeShopData                    │
│ 4. Size: 4                                          │
│ 5. Rellena cada slime:                              │
│    - Slime Rosa (precio 300)                        │
│    - Slime Planta (precio 250)                      │
│    - Slime Fuego (precio 400)                       │
│    - Slime Toxico (precio 350)                      │
└─────────────────────────────────────────────────────┘

TAREA 4: Crea los sprites (variable)
┌─────────────────────────────────────────────────────┐
│ OPCIÓN A: Descarga del internet                     │
│   Busca en OpenGameArt.org o Itch.io                │
│                                                     │
│ OPCIÓN B: Genera con IA                             │
│   Usa ChatGPT + DALL-E, Midjourney, etc             │
│                                                     │
│ OPCIÓN C: Crea tú mismo                             │
│   Aseprite, GIMP, Pixilart.com, etc                 │
│                                                     │
│ Guarda como:                                        │
│   SlimeRosa.png, SlimePlanta.png, etc               │
│   En: Assets/Sprites/                               │
└─────────────────────────────────────────────────────┘

TAREA 5: Importa los sprites en Unity (2 min)
┌─────────────────────────────────────────────────────┐
│ 1. Copia los 4 PNG a Assets/Sprites/                │
│ 2. Para CADA imagen:                                │
│    ✓ Selecciona en Project                          │
│    ✓ Texture Type → Sprite (2D and UI)              │
│    ✓ Click "Apply"                                  │
│ 3. En SlimeShopData, asigna cada imagen             │
└─────────────────────────────────────────────────────┘

═════════════════════════════════════════════════════════════════════════════

✓ Ves los 4 slimes con sus precios
✓ Haces click para ver detalles
✓ Compras con cristales
