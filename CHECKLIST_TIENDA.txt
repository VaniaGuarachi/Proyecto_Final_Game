CONFIGURACIÓN EN UNITY (DEBES HACERLO TÚ)
═══════════════════════════════════════════

PASO 1: PREPARAR LA ESCENA TIENDA
────────────────────────────────
○ Abre la escena: Assets/Scenes/Tienda.unity
○ Crea un Canvas
  ○ Click derecho en la jerarquía → UI → Canvas
  ○ Renombra a: "ShopCanvas"

PASO 2: CREAR EL PANEL PRINCIPAL
──────────────────────────────────
○ Click derecho en ShopCanvas → UI → Panel
○ Renombra a: "ShopPanel"
○ Configura Rect Transform:
  ○ Width: 800
  ○ Height: 600
  ○ Pos X: 0, Pos Y: 0

PASO 3: CREAR PANEL SUPERIOR (TÍTULO)
──────────────────────────────────────
○ Click derecho en ShopPanel → UI → Panel
○ Renombra a: "HeaderPanel"
○ Rect Transform: Height: 100
○ Click derecho en HeaderPanel → UI → TextMeshPro - Text
○ Renombra a: "TitleText"
○ En Text Input, escribe: "TIENDA DE SLIMES"

PASO 4: CREAR PANEL DE SLIMES (SCROLL)
───────────────────────────────────────
○ Click derecho en ShopPanel → UI → Scroll View
○ Renombra a: "SlimesPanel"
○ Desmarca "Horizontal"
○ Renombra el "Content" dentro a: "SlimesContainer"
○ Rect Transform: Width: 150, Height: 500

PASO 5: CREAR PANEL DE DETALLES
───────────────────────────────
○ Click derecho en ShopPanel → UI → Panel
○ Renombra a: "DetailsPanel"
○ Rect Transform: Width: 400, Height: 500
○ Pos X: 200, Pos Y: 0

○ DENTRO de DetailsPanel, crea:
  
  ○ Image (del slime)
    ○ Click derecho en DetailsPanel → UI → Image
    ○ Renombra a: "SlimeImage"
    ○ Rect Transform: Width: 250, Height: 250
  
  ○ Text (nombre)
    ○ UI → TextMeshPro - Text
    ○ Renombra a: "SlimeNameText"
    ○ Text Input: "Nombre del Slime"
    ○ Rect Transform: Pos Y: -130
  
  ○ Text (precio)
    ○ UI → TextMeshPro - Text
    ○ Renombra a: "PriceText"
    ○ Text Input: "Precio: 0"
    ○ Rect Transform: Pos Y: -180
  
  ○ Text (descripción)
    ○ UI → TextMeshPro - Text
    ○ Renombra a: "DescriptionText"
    ○ Text Input: "Descripción"
    ○ Rect Transform: Width: 350, Height: 100, Pos Y: -240
  
  ○ Button (Comprar)
    ○ UI → Button
    ○ Renombra a: "BuyButton"
    ○ Text: "COMPRAR"
    ○ Rect Transform: Width: 150, Height: 50, Pos Y: -380
  
  ○ Text (Cristales)
    ○ UI → TextMeshPro - Text
    ○ Renombra a: "CrystalsText"
    ○ Text Input: "Cristales: 0"
    ○ Rect Transform: Pos Y: 240

PASO 6: CREAR BOTÓN CERRAR
────────────────────────
○ Click derecho en ShopPanel → UI → Button
○ Renombra a: "CloseButton"
○ Text: "CERRAR"
○ Rect Transform: Width: 150, Height: 50, Pos X: 350, Pos Y: -520

PASO 7: CREAR PREFAB DEL BOTÓN DE SLIME
─────────────────────────────────────────
○ Click derecho en ShopCanvas → UI → Button
○ Renombra a: "SlimeButtonTemplate"
○ Rect Transform: Width: 80, Height: 100
○ Borra el componente "Text (TMP)" del botón
○ Click derecho en SlimeButtonTemplate → UI → Image
○ Renombra a: "SlimeIcon"
○ Rect Transform: Width: 80, Height: 80
○ Arrastra "SlimeButtonTemplate" a: Assets/Prefabs/UI/
○ Borra "SlimeButtonTemplate" de la escena

PASO 10: CREAR SPRITES
───────────────────────
○ Crea o descarga 4 imágenes PNG de tus slimes
○ Coloca las imágenes en: Assets/Sprites/
  ○ SlimeRosa.png
  ○ SlimePlanta.png
  ○ SlimeFuego.png
  ○ SlimeToxico.png
○ Para cada imagen:

  ○ En Inspector: Texture Type → Sprite (2D and UI)
  ○ Click "Apply"

PASO 11: CREAR ZONA DE TIENDA EN MAINSCENE
──────────────────────────────────────────
○ Abre MainScene
○ Click derecho en la jerarquía → Create Empty
○ Renombra a: "ShopArea"
○ Posiciona en la zona donde debe estar la tienda
○ Add Component → BoxCollider2D
○ Marca "Is Trigger" ✓
○ Ajusta el tamaño del collider (Size)
○ Add Component → ShopTrigger
○ En ShopTrigger:
  ○ Shop Key: T (por defecto, no cambies)
  ○ Shop UI: [Debe haber un ShopUI en MainScene también]

○ Ctrl+V (pegar)
○ En ShopArea, en ShopTrigger:
  ○ Shop UI: [Arrastra el ShopUI de MainScene]

ERRORES COMUNES
═══════════════

❌ "ShopUI no aparece en el campo"
→ Asegúrate de haber agregado el script ShopUI al Canvas

❌ "El botón de comprar no funciona"
→ Verifica que tengas el ResourceManager en la escena con cristales

❌ "No veo las imágenes de los slimes"
→ Importa las imágenes como Sprite (2D and UI)

❌ "Cuando presiono T no se abre la tienda"
→ Verifica que:
  • El collider sea un Trigger
  • El personaje tenga el tag "Player"
  • El ShopTrigger esté asignado correctamente
